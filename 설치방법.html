일일 챌린지 작동 방식

  • 요일별 난이도 자동 변경: 일=보통, 월=쉬움, 화=보통, 수=어려움, 목=보통, 금=어려움, 토=전문가
  • 씨드 기반 결정론적 퍼즐: 같은 날에 접속한 모든 사람이 같은 퍼즐을 받음 (날짜 = 씨드)
  • 스트릭 시스템: 매일 1회 완료시 연속 일수 증가. 하루라도 빼먹으면 1일로 리셋
  • 최장 스트릭: 본인 최고 기록은 영구 보존 (현재 스트릭이 깨져도 남음)
  • 오늘 완료 후 재플레이: 가능하지만 스트릭 기록은 갱신 안 됨

2Netlify Drop 호스팅 (PC에서)

  1. 이 sudoku-pwa 폴더가 압축돼있으면 먼저 압축 해제하세요
  2. PC 브라우저(크롬/사파리/엣지 다 됨)로 https://app.netlify.com/drop 접속
  3. 화면 가운데 점선 박스에 sudoku-pwa 폴더 통째로 드래그&드롭
  4. 10~30초 안에 자동 URL 생성 → 메모해두기
예시: https://amazing-pasteur-8f3b2c.netlify.app

※ 회원가입 불필요. URL은 영구히 유지. 나중에 코드 수정하고 같은 사이트에 다시 드롭하면 자동 갱신됨.

⚠️ 아이폰 설치 전 필독

  • 반드시 사파리(Safari) 사용 — 크롬·웨일·네이버 ❌ (애플이 PWA 설치를 사파리에서만 허용함)
  • iOS 16.4 이상 권장 (그 이전 버전도 작동하지만 일부 기능 제한)
  • 시크릿 탭(개인정보 보호 탭) ❌ — 일반 탭에서 진행
  • 설치 전에 한 번 사파리로 URL을 열어서 게임이 정상 로딩되는지 확인 권장

4아이폰: 사파리로 설치 (단계별)

STEP 4-1. 사파리에서 URL 열기

  1. 홈 화면에서 사파리 앱 탭
  2. 주소창에 받은 URL 입력 (또는 카톡에서 복사한 링크 붙여넣기)
  3. 스도쿠 게임이 뜨는지 확인. 일일 챌린지 배너도 보일 거예요

STEP 4-2. 공유 메뉴 열기

  1. 화면 하단 가운데 공유 버튼 (네모 + 위로 향한 화살표 ↑) 탭
  2. iOS 14 이전에서는 하단이 아니라 상단 우측에 있을 수 있음
  3. 탭하면 아래에서 공유 시트가 올라옴

STEP 4-3. "홈 화면에 추가" 선택

  1. 공유 시트를 아래로 스크롤 → 액션 목록 등장
  2. "홈 화면에 추가" 항목 탭 (아이콘이 + 모양)
  3. 다음 화면에서 앱 이름 확인 (기본값: 스도쿠) → 우측 상단 "추가" 탭
  4. 사파리가 자동으로 닫히면서 홈 화면으로 이동
  5. 9칸 격자 + "스" 글자 아이콘이 홈 화면에 등장 ✨

STEP 4-4. 설치 확인

  • 홈 아이콘 탭 → 주소창 없는 풀스크린으로 게임 실행 = ✅ 설치 성공
  • 비행기 모드 켜고 다시 열기 → 정상 작동하면 ✅ 오프라인 캐싱 정상
  • 기록은 폰에 영구 저장 (앱 삭제 전까지)

5커스텀 도메인 연결

기본 URL(amazing-puzzle-xyz.netlify.app) 대신 sudoku.본인이름.com 같은 본인 도메인으로 바꾸기

5-1. 도메인 구매 (이미 있으면 스킵)

업체특징가격(연)
Cloudflare Registrar최저가, 갱신가 동일, 영문약 $10 (.com)
가비아한국어, 결제 편리약 22,000원 (.com)
Namecheap중간 가격, 영문약 $13 (.com)
후이즈한국어, 다양한 TLD약 24,000원 (.com)

※ 처음 1년 할인가 말고 갱신가를 비교하세요. Cloudflare가 차이가 큽니다.

5-2. Netlify에 도메인 등록

⚠️ 이 단계부턴 Netlify 회원가입 필요 (구글 로그인 가능, 무료)

  1. Netlify Drop으로 만든 사이트로 이동 (app.netlify.com → 사이트 목록)
  2. 구글/깃허브로 회원가입 → 사이트 자동 연결
  3. 좌측 메뉴 "Domain management" → "Add a domain"
  4. 본인 도메인 입력 (예: sudoku.example.com 또는 그냥 example.com) → "Verify"
  5. Netlify가 안내하는 DNS 설정값 메모: 보통 CNAME 또는 A 레코드 값

5-3. 도메인 등록업체에서 DNS 설정

두 가지 패턴:

패턴 A. 서브도메인 (예: sudoku.example.com)

  • 도메인 관리 페이지 → DNS 레코드
  • 새 레코드 추가:
    • Type: CNAME
    • Name(호스트): sudoku
    • Value(값): 여러분사이트.netlify.app (Netlify에서 알려준 주소)
    • TTL: 자동 또는 3600

패턴 B. 루트 도메인 (예: example.com)

  • 새 레코드 추가:
    • Type: A
    • Name: @
    • Value: 75.2.60.5 (Netlify Load Balancer IP — 변동 가능, Netlify에서 안내한 값 사용)
  • www 처리용 CNAME도 별도 추가 (선택):
    • Type: CNAME, Name: www, Value: 여러분사이트.netlify.app

5-4. DNS 전파 대기 + HTTPS 자동 발급

  • DNS 변경 반영까지 10분 ~ 24시간 (보통 1시간 이내)
  • Netlify가 자동으로 Let's Encrypt SSL 인증서 발급 → HTTPS 활성화
  • Domain management 페이지에서 녹색 "HTTPS Active" 표시가 뜨면 완료
  • 이제 https://sudoku.본인도메인.com으로 접속 가능

5-5. 폰에서 재설치

  1. 홈 화면의 기존 앱 아이콘 길게 눌러 "앱 삭제" (기록도 함께 사라짐 ⚠️)
  2. 사파리에서 새 도메인 URL 열기
  3. 다시 "홈 화면에 추가"

⚠️ 도메인 변경 시 localStorage가 새 도메인에서 시작하므로 기존 기록은 사라집니다. 기록 보존이 중요하면 도메인을 처음부터 정해두는 게 좋아요.

💡 추천 도메인 패턴

  • sudoku.본인이름.com — 본인 메인 도메인이 있다면 서브도메인으로
  • 본인영문이름-sudoku.com — 별도 짧은 도메인
  • 주명게임.com — 한글 도메인 (.kr 가능). 단 사파리 주소창에서 퓨니코드(xn--...) 변환되는 경우 있음

가장 깔끔한 건 이미 있는 본인 도메인 + 서브도메인. 신규 구매시 Cloudflare Registrar가 가성비 갑입니다.

⚠️ 문제 해결

설치 관련

  • "홈 화면에 추가" 메뉴가 안 보여요 → 사파리 맞는지 확인. 시크릿 탭 ❌. 페이지 완전히 로딩 후 시도
  • 아이콘이 빈 사각형으로 떠요 → 첫 번째 방문 시 PNG 로드 안됨. URL 새로고침 후 재설치
  • 설치는 됐는데 풀스크린 아니에요 → 홈에서 다시 탭. iOS 16 미만은 일부 풀스크린 버그 있음

오프라인 관련

  • 비행기 모드에서 안 열려요 → 한 번이라도 온라인에서 열어 캐싱돼야 함. 켰다 끈 후 비행기 모드 시도
  • 업데이트가 반영 안돼요 → 사파리 설정 → "사이트 데이터 지우기" 후 재설치, 또는 앱 삭제 후 재설치

기록 관련

  • 기록이 사라졌어요 → 사파리에서 사이트 데이터를 지웠거나, 도메인이 바뀌었거나, "사파리 추적 방지"가 7일+ 미접속 데이터를 자동 삭제. iOS 설정 → Safari → 고급 → "사이트 데이터" 확인
  • 기록 백업하고 싶어요 → 향후 추가 가능 (CSV 익스포트 기능 등). 요청하시면 만들어드림

👥 와이프와 함께 즐기기

커플 랭킹 시스템 + 게임 업데이트 운영 가이드

🎯 한 줄 요약

같은 Netlify URL을 둘이 공유하면 자동으로 모든 게 됩니다:

  • ✅ 둘 다 같은 사이트에서 PWA 설치 (각자 폰에 별도 앱 + 별도 진행)
  • ✅ 진행 상황은 각자 폰의 localStorage에 저장 (서로 침범 X)
  • ✅ "👥 비교" 버튼으로 카톡 통해 코드 주고받으며 누가 부자인지 확인
  • ✅ 게임 업데이트시 한 명이 Netlify에 새 폴더 드롭 → 둘 다 자동 업데이트

1처음 셋업 (한 번만)

  1. 주명님이 Netlify Drop으로 호스팅 (전에 받은 URL 그대로)
  2. 그 URL을 와이프에게 카톡 "나에게 보내기" 또는 "공유"로 전달
  3. 각자 사파리/크롬으로 URL 열기
  4. 각자 "홈 화면에 추가" 또는 "앱 설치"
  5. 각자 별도의 진행 시작 (localStorage 분리됨)

2👥 코드 비교 시스템 사용법

2-1. 처음 비교할 때 (각자 한 번씩)

  1. 주명님: 헤더 우측 👥 버튼 탭
  2. "내 이름 정하기" 프롬프트 → "주명" 입력 (이름은 나중에 변경 가능)
  3. "📋 내 코드 복사" 버튼 → 코드가 클립보드에 복사됨
  4. 카톡 와이프 채팅창에 붙여넣기 → 전송

2-2. 받은 코드 입력

  1. 와이프가 보낸 코드를 꾸욱 누르고 복사
  2. 주명님 앱 → 👥 → "📥 코드 붙여넣기"
  3. 복사한 코드 붙여넣고 확인
  4. 화면에 둘의 통계 비교가 표 형태로 표시 ✨

3🔄 게임 업데이트 자동 받기

제가 새 기능 만듦
→
새 index.html 전달
→
주명님 폴더에 덮어쓰기
→
Netlify Drop에 다시 끌어다 놓기
→
와이프+주명님 자동 업데이트 ⚡

3-1. 핵심 원리: Service Worker가 자동 갱신

  • Netlify에 새 버전 올라가면 SW가 백그라운드에서 캐시 갱신
  • 다음 앱 실행시 자동으로 새 버전
  • 강제 즉시 적용: 앱 닫고 다시 열기

3-2. 더 자동화하려면 (선택 — GitHub 연동)

나중에 더 편하게 하려면 이 흐름:

  1. GitHub 무료 계정 만들기
  2. 저장소(Repository) 만들고 sudoku-pwa 폴더 업로드
  3. Netlify에서 GitHub 연동 (Site Settings → Build & Deploy)
  4. 이후엔 제가 코드 push만 하면 자동 배포됨
  5. 주명님은 아무것도 안 해도 됨

셋업 30분, 그 후 영구히 자동. 원하시면 가이드 따로 드림.

⚠️ 알아두실 점

  • 각자 진행은 분리됨 — 와이프가 황금성 만들어도 주명님 LV는 그대로. 별도 게임
  • 코드는 그 시점 스냅샷 — 와이프 코드 받은 후 와이프가 더 플레이해도 비교는 받은 시점 기준. 새로 비교하려면 새 코드 받아야 함
  • 24시간 이상 지난 코드는 경고 표시됨 — 새 코드 받으세요
  • 이름 변경 가능 — 👥 화면에서 "변경" 링크
  • 코드 안에 위치 정보·개인정보 없음 — 통계만 들어있음. 카톡 공유 안전
